# Desafio-Dio

🍝 Desafio DIO – Minha primeira página HTML

Este repositório foi desenvolvido como parte dos meus estudos no curso da DIO (Digital Innovation One), com o objetivo de colocar em prática os primeiros conceitos de HTML.

O projeto consiste em uma página simples com uma receita de macarronada, utilizando elementos HTML para estruturar e organizar o conteúdo.

🎯 Objetivo do projeto

Praticar a estruturação de uma página web utilizando HTML, trabalhando com textos, títulos, imagens, listas e links internos.

💻 Tecnologias utilizadas

HTML5

📚 Conceitos praticados

Durante o desenvolvimento, foram utilizados:

Estrutura básica de um documento HTML.

Títulos e subtítulos (h1, h2).

Parágrafos (p).

Formatação de texto (strong).

Inserção de imagens (img).

Listas ordenadas e não ordenadas (ol, ul, li).

Links internos utilizando âncoras (a e id).

🚀 Resultado

A página apresenta uma receita de macarronada, dividida em três partes:

Ingredientes.

Modo de preparo.

Resultado final.

Também foram adicionados links internos para facilitar a navegação entre as seções da receita.

🌱 Aprendizado

Este projeto representa uma das minhas primeiras experiências práticas com HTML. A proposta foi aprender fazendo, conhecer a estrutura de uma página web e desenvolver familiaridade com as principais tags utilizadas na construção de sites.

Este é apenas o começo da minha jornada no desenvolvimento web!
